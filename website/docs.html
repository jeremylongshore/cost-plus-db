Technical Details

What's the difference between Shared and Dedicated?
  • Shared ($49/mo): Your database shares ONE PostgreSQL instance with other customers on the same VPS. Each customer has their own isolated database + user. Security ensures you can't access other customers' data.
  • Dedicated ($89/mo): You get an entire VPS to yourself. ONE PostgreSQL instance running only your database(s).
  • Pro/Enterprise: Same as Dedicated but with more resources (CPU/RAM/storage).

Learn more: Pricing Structure

What PostgreSQL version do you offer?

PostgreSQL 16 (latest stable). We don't offer multiple versions to avoid confusion - you get the best, most secure version available.

How do backups work?
  • Daily automated backups using pgBackRest
  • 30-day retention - we keep your backups for a month
  • 7-day point-in-time recovery - restore to any moment in the last week
  • Encrypted and stored in Wasabi S3 - multi-region redundancy
  • Monthly restoration testing - we verify backups actually work

Learn more: Operations Manual

How secure is CostPlusDB?
  • ✅ SSL/TLS enforced on all connections
  • ✅ scram-sha-256 password encryption
  • ✅ SSH key authentication only (no passwords)
  • ✅ UFW firewall + fail2ban intrusion prevention
  • ✅ Automatic security updates
  • ✅ Per-customer database isolation
  • ✅ Encrypted backups

Learn more: Security Practices

How do I connect to my database?

After provisioning, you'll receive:

  • Host: Server IP address
  • Port: 5433 (non-default port for security)
  • Database: your_company_db
  • User: your_company_user
  • Password: Secure random password
  • SSL: Required (sslmode=require)

Connection string example:

postgresql://your_user:password@server_ip:5433/your_db?sslmode=require
