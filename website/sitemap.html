Page Relationships

Understanding how pages connect:

Reliability (planning) → Incident Response (active crisis) → Emergency (deep dive)

"How we prevent failures"   "What to do RIGHT NOW"      "Detailed technical procedures"

Example Journey: Database Goes Down

1. You notice database is down
   ↓
2. Go to Incident Response
   - Clear "what to do now" instructions
   - Contact information prominent
   - Self-service diagnostics
   ↓
3. If you want more details: Emergency Procedures
   - Backup operator system
   - Incident post-mortems
   - Technical deep dive

1. Land on Homepage
   - See the pitch, pricing example
   ↓
2. Check Calculator
   - See exact pricing for your needs
   ↓
3. Read Reliability
   - Understand uptime, backups, limitations
   ↓
4. Review Transparency Hub
   - See actual internal docs
   - Verify cost calculations
   ↓
5. Decide and Request Consultation
