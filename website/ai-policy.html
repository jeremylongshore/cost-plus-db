AI & Automation Usage

  • Code Review: Security audits and configuration checks

NEVER used on customer data:

Customer Data Policy

What Data We Collect

Infrastructure Data (Required):

  • Connection logs (IP, timestamp, success/fail)
  • Performance metrics (query count, DB size)
  • Backup metadata (size, timestamp)
  • Billing info (Stripe handles payments)

What We DON'T Collect:

  • Your database schema
  • Your table contents
  • Your application data
  • Your query contents

Who Can Access Your Data

Who Access Level Purpose
Jeremy (Owner) Admin (with permission) Setup, maintenance, debugging
Automated backups Read-only snapshot pgBackRest backup process
Monitoring Connection count only Betterstack uptime checks

We NEVER:

  • Sell your data to third parties
  • Use your data for AI training
  • Share with other customers
  • Access without permission (except emergencies)

Emergency Access

When we might access WITHOUT permission:

  1. Active security attack detected
  2. Data corruption during backup verification
  3. Valid court order or subpoena

You'll be notified: Within 1 hour via email + full incident report within 24 hours

Automation Boundaries

Fully Automated (No Human Review)

  • Daily backups (pgBackRest)
  • Security updates
  • SSL certificate renewal
  • Monitoring alerts
  • Log rotation

Semi-Automated (Human Review Required)

  • Database provisioning (script + Jeremy verification)
  • PostgreSQL upgrades
  • Firewall changes
  • Support responses (AI drafts, Jeremy sends)

🚫 Manual Only (No Automation)

  • Customer onboarding decisions
  • Pricing negotiations
  • Security incident response
  • Data deletion requests
  • Refund processing
